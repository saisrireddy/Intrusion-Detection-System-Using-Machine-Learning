# Dataset for Tree-Based IDS

**CICIDS2017_sample.csv**: The randomly sampled subset of CICIDS2017 dataset used in the tree-based intrusion detection system implementation.

This sample contains network traffic data from the CICIDS2017 dataset, which includes both benign traffic and various attack types. The dataset is used to train and evaluate the tree-based ensemble models (Decision Tree, Random Forest, Extra Trees, and XGBoost).
